# Invitation Card Base

Base project chuyển từ Next.js/JavaScript sang React + TypeScript + Vite.

## Đã giữ lại

- Luồng phong thư → lời mời → trả lời → modal lời nhắn → thiệp.
- Cấu trúc component tương ứng với logic project gốc.
- Điểm mở rộng cho nút NO, hiệu ứng, gửi Google Apps Script và thiệp cuối.

## Đã bỏ

- Toàn bộ hình ảnh.
- Toàn bộ audio.
- Toàn bộ CSS/SCSS.
- Next.js và JavaScript.

## Chạy project

```bash
npm install
npm run dev
```

Build production:

```bash
npm run build
```
